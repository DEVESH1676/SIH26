# Integrations

## External APIs

### Ollama (Primary LLM)

- **Endpoint:** `http://192.168.137.1:11434`
- **Protocol:** REST (`/api/chat`)
- **Model:** `qwen2.5-gpu:latest`
- **Used by:** `core/rag.py` — `ResolutionEngine._generate_ollama()`
- **Auth:** None (local network)
- **Timeout:** 60 seconds (hardcoded in `rag.py`)
- **Streaming:** Disabled for resolution generation (`stream: False`), enabled for data generation (`stream: True` in `data/generate_data.py`)
- **Note:** Also used for synthetic data generation via `deepseek-v3.2:cloud` model (cloud routing through local Ollama instance)

### Groq API (Alternative LLM)

- **Endpoint:** Groq cloud (via `langchain-groq`)
- **Model:** `llama3-70b-8192`
- **Used by:** Configured in `config.py` but **currently disabled** (`USE_GROQ = False`)
- **Auth:** `GROQ_API_KEY` from `.env`
- **Note:** Designed as a fast cloud fallback when Ollama is unavailable

## Databases

### ChromaDB (Vector Store)

- **Type:** Embedded persistent vector database
- **Storage:** `./chroma_db/` directory (SQLite backend)
- **Collection:** `tickets` (single collection)
- **Distance metric:** Cosine similarity (`hnsw:space: cosine`)
- **Used by:** All `core/` modules via `core/embeddings.py` (singleton pattern)
- **Data volume:** ~150 tickets currently ingested (from `synthetic_tickets_merged.csv`)
- **Operations:**
  - `upsert` — ticket ingestion (`core/embeddings.py`)
  - `query` — similarity search (`core/classifier.py`, `core/rag.py`, `core/agent.py`)
  - `get` — bulk centroid computation (`core/classifier.py`)

## Data Sources

### Synthetic Ticket CSV

- **Path:** `data/synthetic_tickets_merged.csv` (151 lines including header)
- **Schema:** `ticket_id, title, description, category, resolution, priority, department, created_at`
- **Generated by:** `data/generate_data.py` (Ollama `deepseek-v3.2:cloud`), `data/generate_100.py`, `data/generate_100_batch2.py`
- **Note:** The file is named `synthetic_tickets_merged.csv` but `app.py` references `synthetic_tickets.csv` — potential mismatch

## External Services

- **Google Fonts:** `Outfit` font family loaded via CDN in `app.py` CSS
- No other external service integrations (no auth providers, no webhooks, no monitoring services)
